## Instrucciones para correr la asignación
Dentro de la terminal, realizar lo siguiente:

1. Clonar el repositorio en su computadora.
2. Instalar las dependencias ejecutando `npm install`
3. Iniciar el servidor de desarrollo utilizando `npm run dev`
4. Abrir el navegador en la URL que aparece en la terminal. Por lo general, dicha URL corresponderá a http://localhost:5173
